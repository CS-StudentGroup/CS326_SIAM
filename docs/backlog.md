Product Backlog – CampusConnect
1
User Story: As a student, I want to create an account so that I can access the platform.
Priority: High
Story Points: 3
Acceptance Criteria:

User can register with email and password
Validation for required fields
Error shown for duplicate email

2
User Story: As a user, I want to log in so that I can access my dashboard.
Priority: High
Story Points: 2
Acceptance Criteria:

User can log in with valid credentials
Error message for invalid login
Redirect to dashboard after login

3
User Story: As a student, I want to create tasks so that I can track my assignments.
Priority: High
Story Points: 5
Acceptance Criteria:

User can add task title and due date
Task appears in task list
Task can be saved successfully

4
User Story: As a user, I want to edit tasks so that I can update details.
Priority: Medium
Story Points: 3
Acceptance Criteria:

User can modify task details
Changes are saved correctly
UI updates immediately

5
User Story: As a user, I want to delete tasks so that I can remove completed ones.
Priority: Medium
Story Points: 2
Acceptance Criteria:

User can delete a task
Confirmation prompt appears
Task is removed from list

6
User Story: As a student, I want to view upcoming events so that I stay informed.
Priority: High
Story Points: 5
Acceptance Criteria:

Events are displayed in a list
Each event shows date and title
Events are sorted by date

7
User Story: As an organizer, I want to create events so that students can join.
Priority: Medium
Story Points: 5
Acceptance Criteria:

Organizer can input event details
Event is saved to database
Event appears in event list

8
User Story: As a user, I want to join events so that I can participate.
Priority: Medium
Story Points: 3
Acceptance Criteria:

User can click “Join”
System confirms participation
Event shows joined status

9
User Story: As a user, I want notifications so that I don’t miss deadlines.
Priority: Low
Story Points: 8
Acceptance Criteria:

Notifications appear before due date
User can view notification list
Notifications are time-based

10
User Story: As a user, I want to log out so that my account is secure.
Priority: High
Story Points: 1
Acceptance Criteria:

User can log out successfully
Session is cleared
Redirect to login page
