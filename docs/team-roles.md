# Team Roles – USTP Nexus

## Overview

Roles are assigned per sprint and may rotate in the next iterations to ensure equal contribution and learning.

---

## Core Roles

### Project Manager / Scrum Master

* Ensures sprint progress is on track
* Facilitates meetings and task coordination
* Removes blockers and manages priorities

---

### QA Lead

* Tests features before submission
* Reports bugs and inconsistencies
* Ensures acceptance criteria are met

---

### DevOps / Repository Manager

* Manages GitHub repository
* Handles commits, branches, and merges
* Ensures code is properly organized and pushed

---

### Documentation Lead

* Maintains all project documentation
* Updates backlog, sprint plan, and schedule
* Ensures documents are complete and properly formatted

---

### Security Lead

* Ensures user data (login, accounts) is handled securely
* Checks for basic vulnerabilities (e.g., weak validation, unauthorized access)
* Reviews authentication and access control logic
